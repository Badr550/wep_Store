# 🎮 LUGX Gaming Website

A simple responsive gaming website built using HTML5 and CSS3.

---

## 📌 About the Project

This project is a multi-page gaming website that includes a landing page, trending games section, most played games, categories, and a contact form page.

It focuses on practicing layout design and building clean UI using only HTML and CSS.

---

## 🛠 Tech Stack

- HTML5  
- CSS3  
- Flexbox  
- Google Fonts (Poppins)

---

## 📁 Pages

- Home Page (index.html)  
- Contact Page (contactUs.html)

---

## 🎯 Features

- Clean and modern UI design  
- Responsive layout using Flexbox  
- Reusable components (buttons, cards, sections)  
- Hover effects for better user experience  
- Simple contact form UI  

---

## 🚀 Future Improvements

- Make the website fully responsive for mobile devices  
- Add JavaScript interactivity  
- Improve form validation
